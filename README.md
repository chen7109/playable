# Mahjong Slide Match Playable

这是一个基于 Cocos Creator 3.8.6 的麻将滑动连线消除试玩项目。

## 核心功能

- 双层麻将棋盘，当前只允许操作最上层牌。
- 玩家拖动一行或一列中的连续牌块，让相同牌面在同行或同列连通后消除。
- 消除后播放连线、飘字、计分、Combo、倒计时和胜利/失败结算。
- 无可消除路径时自动洗牌，保证试玩流程可以继续。
- 游戏胜利后弹出 `VictoryPanel`，光效旋转，2 秒后跳转 App Store。

## 连通算法

连通判断只在当前可操作层进行。

每张牌会从自身位置向上、下、左、右四个方向做射线扫描：

1. 沿方向跳过空格。
2. 遇到第一张未消除的牌后停止。
3. 如果这张牌和源牌 `matchKey` 相同，则认为这一对可以连通消除。
4. 如果第一张牌不同，则该方向不成立，后面的牌不会继续检查。

这样实现的是“同行/同列无遮挡直连”规则。拖拽结束后会优先检查本次实际移动的牌是否形成配对，避免别处已有配对误判为本次拖拽成功。

## 拖拽逻辑

触摸移动时先根据横纵位移确定拖拽轴向，再收集拖拽方向上的连续牌块段。系统会计算该段牌前方连续空格数量，并把拖拽距离限制在可移动范围内。

松手后按格距换算移动步数，更新逻辑网格和节点坐标，然后执行连通扫描。若成功匹配则消除；否则回弹到原位置。

## 洗牌逻辑

每次消除和提示检查后，系统会调用可玩性检测。

如果当前层没有任何直接消除或可拖拽形成的消除方案，就会对当前层剩余牌的牌面类型重新随机分配，位置不变，只换牌面。洗牌后会再次查找提示；如果随机结果仍然无解，会使用兜底逻辑强制生成一组可见配对，避免试玩卡死。

## 提示逻辑

提示分两步查找：

1. 先扫描当前层所有牌，找已经可以直接连通的相同牌。
2. 如果没有直接配对，就模拟每张牌向四个方向拖拽一格或多格，检查移动后的棋盘是否能形成配对。

找到提示后，相关牌会播放提示动画，开局和玩家长时间无操作时都会触发。

## 运行

使用 Cocos Creator 3.8.6 打开项目，加载 `assets/Game.scene` 后预览即可。

主要脚本：

- `assets/script/GameController.ts`：棋盘、拖拽、连通、消除、洗牌、提示、计分和结算。
- `assets/script/TileView.ts`：单张牌的显示、遮罩、选中和触摸事件转发。
